# FRAME / portfolio montażysty

HTML/CSS/JavaScript bez instalacji. Całą zawartość `dist`, łącznie z folderem `assets`, wgraj do głównego katalogu repozytorium GitHub Pages.

Interakcje: parallax otwarcia, sticky timeline (scroll scrubbing prawdziwego klipu wideo w obie strony), cztery etapy procesu, grading sterowany postępem, suwak dostępny klawiaturą, filtry prac, podgląd wideo z kontrolkami i lokalny brief. Nie ma automatycznego dźwięku ani wysyłki danych. Przy ograniczeniu ruchu w systemie sticky/parallax są wyłączone, a klip można przewijać suwakiem.

Fikcyjna postać Aleksander Wrona. Koncepcje nie są przedstawiane jako komercyjne zlecenia.
